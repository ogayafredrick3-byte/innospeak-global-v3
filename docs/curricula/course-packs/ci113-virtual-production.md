# CI113 — Virtual Production

**Pathway:** Creative Technology & Immersive Media  
**Level:** Advanced  
**Catalogue duration:** 10 Weeks  
**Indicative guided/independent learning hours:** 26  
**Domain:** Programming and software

## Publication status

Owner-authorised for catalogue publication and self-paced enrolment. Independent subject/academic validation remains pending; no external accreditation is claimed. Fixed-date cohorts, instructor-led sessions and regulated delivery are separate offerings.

## Course overview

Virtual Production covers LED walls, real-time rendering, camera tracking, virtual sets, digital doubles, Unreal Engine virtual production and building real-time film and content production pipelines.

### Intended learners

Learners interested in this programme who meet the entry requirements.

### Prerequisites / entry requirements

- Unreal Engine experience
- Basic film production knowledge
- Access to a computer with internet

## Learning outcomes

- Identify the principles, conventions and tools used in Virtual Production.
- Analyse references and translate a brief into clear creative requirements.
- Produce an original Virtual Production artefact using an intentional process and appropriate tools.
- Revise the work using critique, audience needs and explicit quality criteria.
- Apply attribution, consent, accessibility and responsible-use practices in Virtual Production.
