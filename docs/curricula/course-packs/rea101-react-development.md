# REA101 — React Development

**Pathway:** Software & Digital Systems  
**Level:** Intermediate  
**Catalogue duration:** 10 Weeks  
**Indicative guided/independent learning hours:** 26  
**Domain:** Programming and software

## Publication status

Owner-authorised for catalogue publication and self-paced enrolment. Independent subject/academic validation remains pending; no external accreditation is claimed. Fixed-date cohorts, instructor-led sessions and regulated delivery are separate offerings.

## Course overview

React Development covers components, hooks, state management, routing and API integration, building the skills to create modern single-page applications with React.

### Intended learners

Learners interested in this programme who meet the entry requirements.

### Prerequisites / entry requirements

- JavaScript proficiency
- Basic HTML and CSS
- Access to a computer with internet
- Commitment to weekly practice

## Learning outcomes

- Explain the core concepts, terminology and architecture used in React Development.
- Use appropriate tools, data or programming techniques to complete a defined React Development task.
- Create a working digital artefact or analysis that demonstrates React Development skills.
- Test, debug or validate the result using reproducible evidence and stated acceptance criteria.
- Apply privacy, security, accessibility, licensing and maintainability practices relevant to React Development.
