# DS103 — Statistics for Data Science

**Pathway:** Data, Analytics & Intelligent Systems  
**Level:** Intermediate  
**Catalogue duration:** 10 Weeks  
**Indicative guided/independent learning hours:** 26  
**Domain:** Data and artificial intelligence

## Publication status

Owner-authorised for catalogue publication and self-paced enrolment. Independent subject/academic validation remains pending; no external accreditation is claimed. Fixed-date cohorts, instructor-led sessions and regulated delivery are separate offerings.

## Course overview

Statistics for Data Science covers descriptive statistics, probability, distributions, hypothesis testing, confidence intervals, regression, Bayesian statistics and the statistical foundations needed for data science.

### Intended learners

Learners interested in this programme who meet the entry requirements.

### Prerequisites / entry requirements

- Basic mathematics
- Access to a computer with internet

## Learning outcomes

- Explain the core concepts, terminology and architecture used in Statistics for Data Science.
- Use appropriate tools, data or programming techniques to complete a defined Statistics for Data Science task.
- Create a working digital artefact or analysis that demonstrates Statistics for Data Science skills.
- Test, debug or validate the result using reproducible evidence and stated acceptance criteria.
- Apply privacy, security, accessibility, licensing and maintainability practices relevant to Statistics for Data Science.
