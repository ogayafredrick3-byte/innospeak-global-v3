# InnoSpeak Global Catalogue Governance

## Course identity
Course codes are permanent InnoSpeak internal identifiers. Intake years are never embedded in the code, so a course can be revised through future curriculum versions without breaking historical enrolments.

## Versioning
Every course can carry a version, review date and next review date. Technology-heavy and exam-specific courses are reviewed annually. Regulated qualifications are re-verified against the applicable awarding/regulatory body before each new offering.

## Availability
The catalogue distinguishes current/active offerings from planned, under-development and archived content. A course should only be advertised as available when its learning content and delivery path are ready.

## Current integrity correction
`RUS101` was used by both Russian Language and Rust Programming. Rust Programming is now `RST101`, eliminating the collision.

## Long-term rule
The platform is designed to remain usable through future curriculum changes, including 2060, by keeping identifiers stable and changing course versions/content rather than changing historical IDs.
